Accessibility & privacy
Use Tab and Shift+Tab to move through controls. In the resume viewer, press J / K to browse candidates, 1 / 2 / 3 to record a verdict, or Escape to close.
Files are stored on the server you configure. When Gemini is enabled, screenshots can be read with vision; Tesseract is the local fallback. Text extraction makes scanning easier, but the original document remains the source.
AI comparisons are optional and can contain errors. If enabled, selected resume text and criteria are sent to Gemini. They focus on work related evidence; always read the original resumes and make independent decisions.
